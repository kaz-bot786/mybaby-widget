# MyBaby Ultrasound – Website Widgets

This repo hosts two widgets for [mybabyultrasound.co.uk](https://www.mybabyultrasound.co.uk), served via GitHub Pages.

## Widgets

| Widget | URL |
|--------|-----|
| AI Chatbot | `/mybaby-chatbot.html` |
| Review Assistant | `/mybaby-review-widget.html` |

## Auto-update

The chatbot's availability data is refreshed every morning at 7am UTC via GitHub Actions (`update_availability.py`). You can also trigger it manually from the **Actions** tab.

## Embedding on Wix

In Wix Editor: **Add → Embed → Embed a Site** → paste the GitHub Pages URL for each widget.
